告别伪勤奋！3个Notion/飞书配置，每天多睡1小时

那时候刚开始远程办公，我以为只要下载了协作软件，把电脑抱回家，一切就会自然运转。

2020-03-10
阅读时长: 5 分钟

那时候刚开始远程办公，我以为只要下载了协作软件，把电脑抱回家，一切就会自然运转。

结果现实狠狠给了我一巴掌：微信群消息狂轰滥炸，飞书/钉钉的红点永远消不完，明明在电脑前坐了10个小时，关机时却想不起今天到底完成了哪件大事。最崩溃的一次，我在聊天记录里翻了半小时，只为了找一周前老板发的那个“最终版_v3_修改版.pdf”。

你也经历过这种“虚假繁忙”吗？

在这两年的远程办公实操中，我慢慢意识到：让我们疲惫的不是工作本身，而是混乱的信息流。

今天我想分享几个不仅是“好用”，更是能“救命”的高阶玩法。这些设置不需要你会写代码，也不用买昂贵的会员，只要一点点思维上的转变，就能让工具从“监工”变成你的“私人助理”。

沉浸式看板：把“找文件”的时间省下来撸猫

很多新手（包括两年前的我）用Notion或飞书文档时，最大的误区是把它当成了一个**“大号网盘”**。所有的文档按文件夹一层层堆砌，用的时候像在原始森林里开荒。

真正的长期主义玩法，是建立一个**“个人中控台”**。

你的大脑是为了产生灵感而生的，不是为了像硬盘一样存储文件路径的。—— 《打造第二大脑》

真实案例：

我也曾是个“文件夹狂魔”。有一次项目紧急复盘，我需要同时调取产品部的需求文档、设计部的Figma链接和运营部的排期表。这些东西分散在三个不同的群聊和四个不同的文档文件夹里。那天下午，我花在切换窗口和搜索关键词上的时间，大概有40分钟。

痛定思痛，我重构了我的Notion首页。

具体配置方法：

我不再按“部门”分类，而是按“状态”分类。我建立了一个Master Database（主数据库），把所有任务都丢进去，然后利用**Linked View（关联视图）**功能：

  1. “今天做什么”视图： 筛选条件设为 Date is Today 且 Status is In Progress。
  2. “等待我处理”视图： 筛选条件设为 Assignee contains Me 且 Status is Reviewing。

这样设置后，我每天早上打开电脑，不需要去翻几十个文件夹，只需要看一眼首页。

避坑提示： 千万不要一上来就抄网上那种花里胡哨的“人生管理系统”模板。越复杂的系统，维护成本越高，越容易放弃。从最简单的“待办-进行中-已完成”三列看板开始，这就足够解决80%的问题了。

文档“静默会”：让无效会议原地消失

远程办公最大的杀手就是：随时随地的语音通话和漫无边际的视频会。

“在吗？拉个会碰一下。”这句话简直是我的噩梦。很多时候，大家在会上这扯一句那扯一句，半小时过去了，连背景信息都没对齐。

真实案例：

我们团队曾经每周一上午有长达2小时的例会，十几个人轮流汇报，大部分时间我都在神游（或者偷偷切屏看剧）。后来我们引入了飞书/Lark的**“飞阅会”**模式。

现在的流程是这样的： 会议开始前15分钟，发起人把写满议题的文档发出来。会议开始后的前10分钟，全员闭麦、禁言，只做一件事：默读文档，并在有疑问的地方直接划线评论。

10分钟后，主持人不讲废话，只针对文档里的评论进行解答。

结果惊人： 原本2小时的会议，现在平均35分钟结束。而且因为是文字留痕，那些没参会的同事，事后看文档评论区，比听录音回放清晰一万倍。

实操建议： 如果你是管理者，下次开会试试强行要求“不准说话，先读文档”。如果你是执行者，试着在别人拉你会时，温和地回一句：“由于信息量比较大，能不能辛苦您先写个文档大纲，我标注一下重点再沟通，这样效率更高？”

这招大概率会让你显得既专业又负责。

自动化小确幸：让机器人替你做“恶人”

在团队协作里，最消耗情绪价值的事情是什么？是催进度。

“亲，周报交了吗？”“那个设计图好了吗？”每次问这种问题，我都觉得自己像个只会复读的讨债鬼。

其实，这种机械性的沟通，完全可以交给Notion的自动化（Automations）或者飞书的捷径/机器人。

高阶玩法拆解：

我在Notion的项目数据库里加了一个简单的自动化规则。

场景： 当我在“任务状态”栏，把一个任务从“进行中”拖到“已完成”时。 动作： 系统会自动给下游的同事（比如测试人员）发送一条Slack/飞书通知：“XX任务已完成，请查收。”

如果是用Notion管理个人进度，我还非常推荐使用**公式（Formula）**来给自己一点视觉上的正反馈。

比如，做一个简单的进度条，看着进度条变满，那种多巴胺分泌的感觉是非常治愈的。

notion // Notion 极简进度条公式示例 if(prop(“Done”) / prop(“Total”) >= 1, “✅ 完成”, slice("▓▓▓▓▓▓▓▓▓▓", 0, round(prop(“Done”) / prop(“Total”) * 10)) + slice("░░░░░░░░░░", 0, 10 - round(prop(“Done”) / prop(“Total”) * 10)) + " " + format(round(prop(“Done”) / prop(“Total”) * 100)) + “%”)

个人习惯分享： 我也设置了一个私人的自动化提醒。我把每周五下午4点设定为**“本周复盘时间”**。飞书机器人会准时给我发一段话：“本周辛苦了！在关闭电脑前，花15分钟整理一下桌面的截图，归档做完的任务吧。”

这个小小的仪式感，这把椅子坐了两年，依然能让我从工作的紧绷状态，平滑过渡到周末的松弛模式。

写在最后的小思考：

读到这里，你有没有发现自己其实一直是在“被工具用”，而不是在“用工具”？

当我们因为一条消息提示就立刻中断当下的深度思考时，我们就已经输给了工具。

远程办公的核心不是那台电脑，也不是那个App，而是对他人的信任和对自己的掌控。

如果你想从明天开始改变，不妨先做这三件小事：

  1. 关闭非紧急消息通知：除了@你的消息，其他的群消息一律静音，每2小时集中查看一次。
  2. 建立一个“首页”：不管用什么软件，给自己搭一个能一眼看到所有核心任务的仪表盘。
  3. 尝试一次“书面沟通”：下次想拉语音时，逼自己先把想法写成不少于200字的文档发给对方。

工具是冰冷的，但使用工具的方式可以是有温度的。希望这些方法，能帮你在这个混合办公的时代，找回属于自己的生活节奏。
